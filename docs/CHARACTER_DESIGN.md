# 角色设计稿 · 拳魂 ARCADE FIST

> 原创街机格斗阵容，向《拳皇》的 3v3 组队淘汰赛与 4 键格斗玩法致敬。
> **所有角色、招式、美术均为原创程序化生成，不使用任何第三方版权素材。**
> 字段与引擎一一对应，详见 [CHARACTER_SCHEMA.md](./CHARACTER_SCHEMA.md)。

## 设计总则

| 维度 | 取值 | 说明 |
|---|---|---|
| 操作 | 4 键（A 拳 / B 重拳 / C 脚 / D 重脚）+ 方向 + 必杀 | 拳皇式极简输入 |
| 赛制 | 3v3 组队淘汰（KOF 标志） | 一方 3 人全灭即负 |
| 气槽 | 满气放必杀，伤害随连段递减 | 零素材特效 |
| 画风 | 程序化像素 + 骨骼动画 | 深色霓虹街机调 |

## 战队一览

```
炎武队 (Blaze Brigade)              幻影队 (Phantom Squad)
  retsua 炎武·烈云  [均衡/波动]        kuro   夜刃·库洛  [突进/十字斩]
  vela   雷光·薇拉  [速度/三连踢]      shira  疾风·希拉  [速度/升龙]
  goro   岩豪·戈罗  [重装/震地]        xue    冰华·雪    [控场/真空波]
```

每队 3 人覆盖「远程 / 速度 / 重装 / 突进 / 对空 / 牵制」六类原型，必杀类型互不重复。

## 炎武队 · Blaze Brigade

### 1. 炎武 · 烈云（retsua）— 队长 / 均衡
- **原型**：攻守均衡的「波动拳」系锚点角色（新手到高手通吃）。
- **背景**：炎武流继承人，奉命带队参加斗魂大会。沉稳可靠，是队伍的中轴。
- **属性雷达**：体力 1.00 · 攻击 1.00 · 速度 1.00 · 射程 1.05
- **必杀 · 烈焰波动弹**（projectile）：身前喷出火球，远程压制与牵制。
- **招牌普攻**：重拳「烈阳拳」中距稳定；轻脚游击。
- **配色**：红橙主调 `#ff7a2f`，火光拖尾。

### 2. 雷光 · 薇拉（vela）— 速度
- **原型**：电系速攻，贴身三连踢打连段。
- **背景**：风雷双修的少女，以诡异步法戏耍对手，队内气氛担当。
- **属性雷达**：体力 0.88 · 攻击 0.90 · 速度 **1.25** · 射程 0.95
- **必杀 · 雷霆三连踢**（rush）：瞬步贴近后三连踢，多段判定。
- **招牌普攻**：高机动轻攻接取消。
- **配色**：冰蓝电光 `#6fd7ff`，闪电拖尾。

### 3. 岩豪 · 戈罗（goro）— 重装
- **原型**：血厚力大、近身定胜负的摔跤手（自定义重招式表）。
- **背景**：退役擂台王，转投炎武队当肉盾，一拳一个小朋友。
- **属性雷达**：体力 **1.28** · 攻击 **1.28** · 速度 0.82 · 射程 1.08
- **必杀 · 崩岩震地击**（shock）：砸地冲击波，近身大伤害。
- **招牌普攻**：自定义「岩拳 / 巨踢」出手慢但每下更疼。
- **配色**：土黄岩色 `#e8b84a`。

## 幻影队 · Phantom Squad

### 4. 夜刃 · 库洛（kuro）— 队长 / 突进
- **原型**：向前瞬斩抓破绽的高手向角色。
- **背景**：幻影流刺客，沉默寡言，专治冒进的对手。
- **属性雷达**：体力 0.95 · 攻击 1.05 · 速度 1.12 · 射程 1.10
- **必杀 · 暗影十字斩**（dash）：突进斩击，抓破绽一击反打。
- **招牌普攻**：突进后接轻攻。
- **配色**：暗紫 `#a95cff`。

### 5. 疾风 · 希拉（shira）— 速度 / 对空
- **原型**：最灵活的游斗者，专属升龙治跳入（自定义快招式表）。
- **背景**：幻影队先锋，身法如风，最爱把跳入的对手挑飞。
- **属性雷达**：体力 0.88 · 攻击 0.90 · 速度 **1.25** · 射程 0.95
- **必杀 · 风影升龙**（uppercut）：对空无敌起手，身前升起能量柱多段判定。
- **招牌普攻**：自定义「迅拳 / 疾脚」出手比全局更快。
- **配色**：风白蓝 `#6fd7ff`。

### 6. 冰华 · 雪（xue）— 控场 / 牵制
- **原型**：冷静的远程控场，真空波封锁走位。
- **背景**：幻影队后卫，以冰华弹幕逼对手进自己的节奏。
- **属性雷达**：体力 0.96 · 攻击 0.98 · 速度 1.00 · 射程 **1.12**
- **必杀 · 冰华真空波**（beam）：身前喷出真空波，向前扩张多段判定。
- **招牌普攻**：中距轻攻消耗。
- **配色**：冰蓝 `#5fd0f0`。

## 必杀类型矩阵

| 类型 | 机制 | 角色 |
|---|---|---|
| projectile 飞行弹 | 远程弹道，一击 | retsua |
| rush 突进连击 | 贴近多段 | vela |
| shock 震地 | 砸地近身大伤 | goro |
| dash 突进斩 | 突进单发重击 | kuro |
| uppercut 升龙 | 对空无敌多段 | shira |
| beam 能量波 | 前方扩张多段 | xue |

> 想加新必杀类型？在 `core/game.js` 的 `fireSpecial` 与 `stepEffects` 各加一个分支即可（见 CHARACTER_SCHEMA.md）。
