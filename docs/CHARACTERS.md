# 拳魂 ARCADE FIST · 原创角色设计稿

> ⚠️ 版权声明：本稿全部角色、招式名、背景、美术均为**原创**，仅**致敬街机格斗（拳皇类）的玩法与体裁**，不复制 SNK《The King of Fighters》的任何角色造型、名称或商标。上线与商用均安全。

本作采用 **3v3 组队淘汰赛**（拳皇标志性赛制）。角色按「战队」组织，玩家选 3 人组队，依次上场，KO 后换下一名；全队 3 人阵亡即负。

---

## 一、战队总览

| 战队 | 名称 | 风格 | 成员 |
|------|------|------|------|
| `team-blaze` | 烈炎队 | 攻守均衡 + 远程压制 + 投技 | 莱恩 / 薇拉 / 戈罗 |
| `team-shadow` | 疾影队 | 突进爆发 + 高速连段 + 控场 | 库洛 / 希拉 / 雪 |

每队三种定位互补：**均衡 / 速度 / 重装（或 控场）**，对应拳皇「主角队」的经典铁三角。

## 二、角色设计稿

### 1. 烈焰 · 莱恩（Ryan）　`team-blaze` · 队长
- **流派**：炎拳流　**定位**：均衡 / 远程压制（Shoto 型）
- **背景**：烈炎队队长，将家传炎之拳法练至收发由心。性格沉稳，是队友的主心骨。
- **像素外形**：火焰红短发、赤红武道服、金黄腰带；体型 normal。
- **普通技**：轻/重拳、轻/重脚、蹲拳、扫堂腿、跳跃拳（通用 4 键）
- **必杀技 · 烈焰波动拳**（type: `projectile`）：推出一枚火焰弹，远程压制，可取消对手突进。
- **数值**：hp 1.0 / atk 1.0 / spd 1.0 / reach 1.0（基准）

### 2. 雷光 · 薇拉（Vela）　`team-blaze`
- **流派**：雷影流　**定位**：速度 / 连段（Speed 型，致敬「电系贵公子」定位）
- **背景**：拥有雷电体质的少女，出招带静电残影，最擅长贴身三连踢打崩对手节奏。
- **像素外形**：银白发、电青紧身战衣、蓝白护腕；体型 slim。
- **普通技**：同通用 4 键，攻击前摇更短。
- **必杀技 · 雷霆三连踢**（type: `rush`）：瞬步贴身，三连踢累计伤害，hit 3 段。
- **数值**：hp 0.88 / atk 0.9 / spd 1.25 / reach 0.95

### 3. 岩豪 · 戈罗（Goro）　`team-blaze`
- **流派**：崩岩流　**定位**：重装 / 投技（Grappler 型）
- **背景**：体型魁梧的摔跤手，一拳能震碎地面，近身即是噩梦，但出手偏慢。
- **像素外形**：寸头、土黄重甲、墨绿长裤；体型 heavy。
- **普通技**：同通用 4 键，单发伤害高、前摇长。
- **必杀技 · 崩岩震地击**（type: `shock`）：砸地产生冲击波，扫地且击飞。
- **数值**：hp 1.25 / atk 1.28 / spd 0.82 / reach 1.05

### 4. 暗影 · 库洛（Kuro）　`team-shadow` · 队长
- **流派**：暗杀流　**定位**：突进 / 反击（Rush 型，致敬「苍焰宿敌」定位）
- **背景**：疾影队领袖，身法如鬼，专抓对手破绽一击毙命，高手向角色。
- **像素外形**：漆黑长发、紫黑披风战衣、暗紫手套；体型 slim。
- **普通技**：同通用 4 键。
- **必杀技 · 暗影十字斩**（type: `dash`）：向前瞬斩，长距离突进高伤。
- **数值**：hp 0.95 / atk 1.05 / spd 1.12 / reach 1.1

### 5. 疾风 · 希拉（Shira）　`team-shadow`
- **流派**：风影流　**定位**：高速 / 连段（Speed 型）
- **背景**：风一般灵敏的游斗者，位移灵活、出招快，适合打持久连段消耗。
- **像素外形**：浅蓝长发、白蓝劲装、青色腰带；体型 slim。
- **普通技**：同通用 4 键，移动更快。
- **必杀技 · 瞬影三连踢**（type: `rush`）：与薇拉同源但更轻快的三连踢。
- **数值**：hp 0.88 / atk 0.9 / spd 1.25 / reach 0.95

### 6. 冰华 · 雪（Xue）　`team-shadow`
- **流派**：冰华流　**定位**：控场 / 远程（Zoner 型，致敬「冰之少女」定位）
- **背景**：冷静的控场者，以冰华弹幕封锁走位，逼对手进入自己的节奏。
- **像素外形**：冰蓝短发、白蓝长袍、霜白长靴；体型 normal。
- **普通技**：同通用 4 键。
- **必杀技 · 冰华散弹**（type: `projectile`）：扇形冰晶弹，中距离封锁。
- **数值**：hp 0.96 / atk 0.98 / spd 1.0 / reach 1.12

## 三、必杀技分类（引擎支持的 4 种 type）

| type | 表现 | 代表角色 |
|------|------|----------|
| `projectile` | 发射飞行道具 | 莱恩（火）、雪（冰） |
| `rush` | 贴身多段连击 | 薇拉、希拉 |
| `shock` | 地面冲击波（扫地） | 戈罗 |
| `dash` | 突进斩击 | 库洛 |

> 要加新必杀只需在 `special.type` 中选其一，或扩展 `game.js` 的 `fireSpecial` 增加新 type —— 角色数据层无需改引擎。

---

## 四、配色（palette 字段）

每个角色 `palette` 含：`skin / hair / top / bottom / belt / shoe / glove / accent / trail`。
`accent` 为主题色（特效与描边），`trail` 为突进残影色。数值见 `core/constants.js` 的 `CHARACTERS`。

---

## 五、换皮指引（快速替换角色）

1. **只换数值/招式**：改 `core/constants.js` 里对应角色的 `stats` / `special`。
2. **换美术**：改 `palette` 配色，或扩展 `core/sprites.js` 的 `drawFighter` 用 `build` 区分体型。
3. **加新角色**：往 `CHARACTERS` 数组 push 一个对象，并视情况加入 `TEAMS`。
4. **套用自有 IP 角色**：把 `CHARACTERS` 整体替换为你的授权角色数据即可，引擎、操作、广告、UI 全部复用（详见 `docs/CHARACTER_SCHEMA.md`）。
